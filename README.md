# Weather Data Analysis

## About the Project

This project is based on the analysis of weather data using Python and Pandas.

The main purpose of this project is to explore the weather dataset and understand different weather conditions using data analysis techniques. The analysis includes temperature, humidity, wind speed, visibility, pressure and weather conditions.

## Dataset

The dataset contains different weather-related attributes such as:

- Date/Time
- Temperature
- Dew Point Temperature
- Relative Humidity
- Wind Speed
- Visibility
- Pressure
- Weather Condition

## Analysis Performed

### Data Inspection

The dataset was explored using Pandas to understand its structure, columns, data types and statistical information.

### Unique Values and Counts

Checked unique values and frequency counts for different columns to understand the data.

### Filtering Data

Filtered the dataset using different conditions to find specific weather records.

### GroupBy Analysis

Used `groupby()` to analyze weather data based on different conditions and calculate relevant values.

### Missing Value Analysis

Checked the dataset for missing/null values and analyzed the available data.

### Statistical Analysis

Calculated statistical measures such as:

- Mean
- Standard Deviation
- Variance
- Minimum Value
- Maximum Value

### Weather Condition Analysis

Analyzed different weather conditions and their relationship with other weather parameters.

### Wind Speed, Visibility and Humidity

Performed analysis on wind speed, visibility and humidity to understand their distribution and behavior in the dataset.
